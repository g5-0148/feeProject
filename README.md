# 🌐 SkillSphere

> A modern student developer community and portfolio-sharing platform built to connect peer developers, showcase technical milestones, and exchange feedback.

---

### 🚀 Live Website
Experience the live project directly in your browser:  
👉 **[https://g5-0148.github.io/feeProject/](https://g5-0148.github.io/feeProject/)**

---

## ✨ Features

- **🔐 User Authentication:** Dedicated Login and Sign-Up interfaces with interactive form validation.
- **📰 Developer Feed:** Publish project updates, attach image previews, add captions, and tag relevant technologies.
- **🏷️ Skill & Tag Filtering:** Browse and filter feed content using technical hashtags (`#React`, `#CSS`, `#Python`, `#DBMS`, `#UI/UX`).
- **💬 Community Interaction:** Like posts, bookmark projects into a private Saved collection, and leave comments.
- **👤 Profile Portfolios:** Dedicated developer profiles showing project stats, followed peers, and personal post history.
- **🌓 Dark / Light Theme:** Integrated toggle supporting clean light mode and a nature-inspired dark mode.

---

## 🛠️ Tech Stack

- **Frontend:** React.js (Vite)
- **Styling:** Custom CSS3 (Flexbox & Grid, CSS Variables)
- **Icons & Assets:** SVGs / Web Icons
- **Hosting:** GitHub Pages
